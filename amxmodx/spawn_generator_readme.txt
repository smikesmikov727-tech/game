                    SPAWN POINT GENERATOR v1.0
                    для Counter-Strike 1.6
                    AMX Mod X 1.9.0
================================================================================

ОПИСАНИЕ:
---------
Плагин для создания и управления точками возрождения игроков.
Поддерживает до 32 безопасных спавнов с защитой от застреваний.

УСТАНОВКА:
----------
1. Скопируйте spawn_generator.sma в addons/amxmodx/scripting/
2. Скомпилируйте плагин:
   - Локально: amxxpc spawn_generator.sma
   - Онлайн: https://amxmodx.org/webcompiler.cgi
3. Скопируйте spawn_generator.amxx в addons/amxmodx/plugins/
4. Добавьте в plugins.ini: spawn_generator.amxx
5. Создайте папку: addons/amxmodx/configs/spawns/
6. Перезагрузите сервер

КОМАНДЫ:
--------
Чат-команда (требуется ADMIN_RCON):
  /spawns             - Открыть меню управления спавнами

Консольные команды:
  amx_spawn_add       - Добавить спавн в текущей позиции
  amx_spawn_del       - Удалить ближайший спавн
  amx_spawn_save      - Сохранить спавны в файл
  amx_spawn_load      - Загрузить спавны из файла
  amx_spawn_clear     - Удалить все спавны
  amx_spawn_show      - Показать все спавны (визуально)
  amx_spawn_auto      - Автоматическая генерация 32 спавнов
  amx_spawn_test      - Проверить безопасность всех спавнов

ИСПОЛЬЗОВАНИЕ:
--------------
1. Подключитесь к серверу с правами ADMIN_RCON
2. Напишите в чат: /spawns
3. Выберите "Авто-генерация" для автоматического создания 32 спавнов
   ИЛИ
   Ходите по карте и добавляйте спавны вручную через "Добавить спавн"
4. Используйте "Показать спавны" для визуализации
5. Используйте "Тестировать спавны" для проверки безопасности
6. Сохраните спавны через "Сохранить спавны"

СИСТЕМА БЕЗОПАСНОСТИ:
---------------------
Плагин автоматически проверяет каждую точку спавна на:
- Наличие земли под ногами
- Отсутствие препятствий (стены, объекты)
- Достаточное пространство над головой (72 юнита)
- Отсутствие воды
- Минимальное расстояние между спавнами (128 юнитов)

При спавне игрока также проверяется:
- Отсутствие других игроков в радиусе 64 юнита
- Случайный выбор из доступных спавнов

ФОРМАТ ФАЙЛА СПАВНОВ:
---------------------
Файлы сохраняются в: addons/amxmodx/configs/spawns/<mapname>.cfg

Формат строки: X Y Z Pitch Yaw Roll Team
- X, Y, Z - координаты позиции
- Pitch, Yaw, Roll - углы поворота
- Team: 0 = любая команда, 1 = CT, 2 = T

Пример:
-1580.0 2628.0 1.0 0.0 90.0 0.0 1

ЦВЕТА ВИЗУАЛИЗАЦИИ:
-------------------
- Зеленый - универсальный спавн (любая команда)
- Синий   - спавн CT
- Красный - спавн T

ТРЕБОВАНИЯ:
-----------
- AMX Mod X 1.9.0 или выше
- Модули: fakemeta, engine, hamsandwich

НАСТРОЙКИ ПЛАГИНА (в коде):
---------------------------
MAX_SPAWNS      = 32      - Максимальное количество спавнов
MIN_SPAWN_DIST  = 128.0   - Минимальное расстояние между спавнами
HULL_CHECK_Z    = 36.0    - Высота проверки коллизии
SAFE_RADIUS     = 32.0    - Радиус безопасной зоны

ИЗВЕСТНЫЕ ОГРАНИЧЕНИЯ:
----------------------
- Автогенерация работает лучше на картах со стандартными спавнами
- На пустых картах без info_player_start/deathmatch нужно добавлять
  спавны вручную
- Максимум 32 точки спавна
