# CSDM Smart Spawn Distribution Plugin

## Описание

Умный плагин для Counter-Strike DeathMatch (CSDM) с интеллектуальной системой распределения респавнов игроков. Использует REAPI для оптимальной производительности.

### Основные возможности

- **Умный алгоритм выбора точки респавна:**
  - Учитывает расстояние до других игроков (союзников и врагов)
  - Проверяет видимость от точки спавна до других игроков
  - Не использует недавно занятые точки спавна
  - Равномерное распределение игроков по карте
  - Взвешенная случайность для естественного геймплея

- **Автоматическая генерация точек спавна:**
  - Сканирование существующих точек спавна на карте
  - Автоматическое сохранение для каждой карты
  - Поддержка точек для конкретных команд (T/CT)

- **Гибкая настройка:**
  - Настраиваемые параметры расстояний
  - Регулировка времени повторного использования точек
  - Консольные команды для управления

## Требования

- **AMX Mod X 1.9.0+**
- **ReAPI** (обязательно)
- **Counter-Strike 1.6** или **CS: Condition Zero**

## Установка

### 1. Компиляция плагина

```bash
# Скопируйте файл в папку scripting
cp addons/amxmodx/scripting/csdm_smart_spawn.sma /path/to/server/addons/amxmodx/scripting/

# Скомпилируйте плагин
cd /path/to/server/addons/amxmodx/scripting/
./compile.sh csdm_smart_spawn.sma
```

Или используйте онлайн компилятор: https://www.amxmodx.org/websc.php

### 2. Установка файлов

```
addons/amxmodx/
├── plugins/
│   └── csdm_smart_spawn.amxx          # Скомпилированный плагин
├── scripting/
│   └── csdm_smart_spawn.sma           # Исходный код
└── configs/
    ├── plugins.ini                     # Добавьте строку: csdm_smart_spawn.amxx
    └── csdm_smart_spawn.cfg           # Конфигурация плагина
```

### 3. Активация плагина

Добавьте в файл `addons/amxmodx/configs/plugins.ini`:

```
csdm_smart_spawn.amxx
```

### 4. Настройка конфигурации

Отредактируйте файл `addons/amxmodx/configs/csdm_smart_spawn.cfg` под свои нужды или добавьте команды в `server.cfg`:

```
exec addons/amxmodx/configs/csdm_smart_spawn.cfg
```

## Настройка

### CVars (Консольные переменные)

```
// Включить/выключить плагин
csdm_smart_spawn 1

// Минимальное расстояние до союзников (в единицах)
csdm_spawn_min_dist_player 300.0

// Минимальное расстояние до врагов (в единицах)
csdm_spawn_min_dist_enemy 500.0

// Время повторного использования точки спавна (в секундах)
csdm_spawn_reuse_time 5.0

// Автоматическая генерация точек спавна
csdm_spawn_autogenerate 1
```

### Рекомендуемые значения

#### Для маленьких карт (aim_*, fy_*):
```
csdm_spawn_min_dist_player 200.0
csdm_spawn_min_dist_enemy 400.0
csdm_spawn_reuse_time 3.0
```

#### Для средних карт (de_dust2, de_mirage):
```
csdm_spawn_min_dist_player 300.0
csdm_spawn_min_dist_enemy 500.0
csdm_spawn_reuse_time 5.0
```

#### Для больших карт (cs_assault, de_nuke):
```
csdm_spawn_min_dist_player 400.0
csdm_spawn_min_dist_enemy 600.0
csdm_spawn_reuse_time 7.0
```

## Команды администратора

Все команды требуют права доступа **ADMIN_MAP**.

### Управление точками спавна

```
csdm_addspawn
```
Добавляет точку спавна в текущей позиции администратора. Встаньте в нужное место, посмотрите в нужном направлении и введите команду.

```
csdm_delspawn
```
Удаляет ближайшую к администратору точку спавна.

```
csdm_savespawns
```
Сохраняет текущие точки спавна для карты в файл `configs/csdm_spawns/<mapname>.spawns`.

```
csdm_loadspawns
```
Загружает точки спавна для текущей карты из файла.

```
csdm_clearspawns
```
Удаляет все точки спавна из памяти (не удаляет файл).

```
csdm_showspawns
```
Выводит информацию о количестве точек спавна и настройках в консоль администратора.

## Создание точек спавна вручную

### Метод 1: Автоматическая генерация (рекомендуется)

1. Запустите карту
2. Плагин автоматически найдет все существующие точки спавна
3. Точки будут сохранены автоматически

### Метод 2: Ручное создание

1. Зайдите на сервер как администратор
2. Включите режим noclip: `sv_cheats 1; noclip`
3. Летайте по карте и в подходящих местах вводите: `csdm_addspawn`
4. Добавьте 30-50 точек для маленьких карт, 50-100 для больших
5. Сохраните точки: `csdm_savespawns`

### Рекомендации по расстановке точек:

- Размещайте точки равномерно по всей карте
- Избегайте мест с плохим обзором (углы, закрытые помещения)
- Не ставьте точки слишком близко к краям карты
- Проверяйте, что игрок не застрянет в текстурах
- Размещайте больше точек в открытых зонах
- Учитывайте баланс команд (или используйте нейтральные точки)

## Как работает умный алгоритм

### Система оценки точек спавна

Каждая точка спавна получает оценку (score) на основе:

1. **Время последнего использования**
   - Недавно использованные точки получают штраф
   - Чем больше времени прошло, тем выше приоритет

2. **Расстояние до союзников**
   - Слишком близкое расположение к союзникам снижает оценку
   - Минимальное расстояние настраивается через `csdm_spawn_min_dist_player`

3. **Расстояние до врагов**
   - Близость к врагам значительно снижает оценку
   - Минимальное расстояние настраивается через `csdm_spawn_min_dist_enemy`

4. **Видимость**
   - Если враг видит точку спавна - дополнительный большой штраф
   - Использует трассировку луча для определения видимости

5. **Взвешенная случайность**
   - Финальный выбор происходит с учетом весов
   - Лучшие точки имеют больший шанс быть выбранными
   - Но даже точки с меньшей оценкой могут быть выбраны (для разнообразия)

## Структура файлов спавнов

Файлы сохраняются в формате:
```
configs/csdm_spawns/<mapname>.spawns
```

Формат строки:
```
<origin_x> <origin_y> <origin_z> <angle_x> <angle_y> <angle_z> <team>
```

Пример:
```
; CSDM Smart Spawn Points
; Карта: de_dust2
; Точек: 64

-123.45 678.90 -32.10 0.00 90.00 0.00 0
456.78 -234.56 64.00 0.00 180.00 0.00 0
...
```

- **origin**: координаты точки (x, y, z)
- **angles**: направление взгляда (pitch, yaw, roll)
- **team**: команда (0 = любая, 1 = T, 2 = CT)

## Оптимизация производительности

### Использование REAPI

Плагин использует REAPI хуки для максимальной производительности:
- `RG_CSGameRules_RestartRound` - сброс состояния при рестарте
- `RG_CBasePlayer_Spawn` - перехват спавна игрока

### Рекомендации

- Оптимальное количество точек: 50-80 для большинства карт
- Слишком много точек (>100) может снизить производительность
- Используйте автогенерацию для быстрой настройки
- Регулярно проверяйте логи на ошибки

## Troubleshooting (Решение проблем)

### Игроки не респавнятся в новых точках

1. Проверьте, что плагин загружен: `amxx list`
2. Проверьте настройку: `csdm_smart_spawn 1`
3. Проверьте количество точек: `csdm_showspawns`
4. Убедитесь, что нет конфликтующих плагинов

### Игроки застревают в текстурах

1. Используйте `csdm_delspawn` рядом с проблемной точкой
2. Добавьте новую точку в безопасном месте
3. Сохраните изменения: `csdm_savespawns`

### Точки спавна не сохраняются

1. Проверьте права доступа к папке `configs/csdm_spawns/`
2. Убедитесь, что папка существует
3. Проверьте логи сервера на ошибки

### Плохая производительность

1. Уменьшите количество точек спавна (оставьте 50-60)
2. Увеличьте `csdm_spawn_reuse_time`
3. Уменьшите `csdm_spawn_min_dist_enemy`
